\begin{abstract}
This document summarizes all testing performed on the Chaos Language Algorithm (CLA) prototype as of 2026-07-10. The pure-Python \texttt{chaoslang} library has been tested on five deterministic dynamical control systems (logistic map, Lorenz-63, Rossler, Mackey-Glass, Lorenz-96) across dimensions 1 through 24, plus a 1024-step $\times$ 20-dimensional OmegaSim-scale smoke run. Every recorded experiment preserves exact symbolic reconstruction. The prototype learns chunk grammars under an approximate MDL objective, with a bounded suffix-trie miner and Jensen-Shannon category proposal path. No non-chaotic controls, shuffled surrogates, held-out evaluation, matched brute-force comparison, or actual OmegaSim traces have been tested yet.
\end{abstract}

\section{Key Findings}

\begin{enumerate}
\item \textbf{Exact reconstruction holds universally.} All 11 recorded experiments (10 baselines + 1 OmegaSim-scale smoke) verify that the learned grammar expands to the original symbol stream.

\item \textbf{Compression degrades with dimension.} At dim 1--3, scores range 44--189 (0.17--0.74 units/symbol). At dim 16--24, scores plateau near 249--252 (0.97--0.98 units/symbol), approaching raw parse cost. This reflects the $4^D$ compound-symbol explosion under direct M1 binning, not absence of dynamical structure.

\item \textbf{Mackey-Glass is most compressible.} Only 4 unique symbols and score 44.4, consistent with its quasi-periodic behavior at these parameters.

\item \textbf{OmegaSim-scale smoke succeeds.} The 1024 $\times$ 20D run completed in 2.55 s with exact reconstruction, 510 unique symbols, and 8 chunk rules. No category edit was accepted, so the JS path was exercised but not validated as beneficial on this run.

\item \textbf{Suffix-trie miner is functional.} The bounded trie miner handles high-cardinality 20D streams without OOM. However, no matched brute-force comparison exists to quantify speedup or memory savings.
\end{enumerate}

\section{Limitations}

\begin{itemize}
\item No non-chaotic controls, shuffled surrogates, or periodic baselines: sensitivity/specificity for chaos detection is unknown.
\item No held-out evaluation: M1 bounds are inferred from the full trajectory.
\item Score is a heuristic proxy, not a calibrated information code.
\item Single-run per parameter setting: no confidence intervals or perturbation sweeps.
\item Peak memory not recorded for any run.
\item No matched brute-force vs.\ trie benchmark.
\item 256-symbol records lack raw stdout, environment captures, and commit identifiers.
\item No actual OmegaSim trace tested: ``OmegaSim-scale'' refers to stream length and dimensionality only.
\item No category edit was accepted in the 1024 $\times$ 20D run; JS clustering benefit is unvalidated.
\end{itemize}
