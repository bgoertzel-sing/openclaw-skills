## 2026-07-10: Insert dynamics-aware embedding before high-D CLA symbolization

**Decision:** Treat the high-dimensional CLA failure as a symbolization problem first: insert a dynamics-aware dimensional embedding and low-cardinality adaptive microstate partition before CLA sees the stream. The initial implementation is a dependency-free Phase-0 baseline: TICA/VAMP-style kinetic map, k-means microstates, shuffled-surrogate excess compression, held-out n-gram baseline log-loss, spectral participation-ratio diagnostics, and deterministic high-D lifts for controls.

**Rationale:** Fixed rectangular M1 symbolization grows as `b^D`, making high-D trajectories produce near-unique compound symbols and destroying recurrence before grammar induction. Decoupling alphabet size `k` from ambient dimension `D` is required before interpreting CLA performance on OmegaSim/OmegaHive-scale vector traces.

**Implementation implications:** Keep fixed M1 as a baseline/control, but use `tica-kmeans` / adaptive microstates for high-D experiments. Label current surrogate and held-out metrics as Phase-0 diagnostics, not final scientific validation. The pure-Python eigensolver is acceptable for small tests but D≈200–300 production work should move to a numerically robust TICA/VAMP backend such as `deeptime`, with PCCA+ category seeding added after the microstate pipeline is validated.

## 2026-07-10: Deeptime backend for production-scale high-D CLA

**Decision:** Add a `deeptime`-backed module (`chaoslang.deeptime_backend`) as the production path for D≈200–300 kinetic-map embedding, PCCA+ category seeding, and implied-timescales diagnostics. Keep the pure-Python MVP in `embedding.py` as a fallback for environments without `deeptime`.

**Rationale:** The pure-Python Jacobi eigensolver is O(D³) and not numerically robust for rank-deficient high-D covariance whitening. `deeptime` provides tested TICA/VAMP implementations, PCCA+ coarse-graining, and CK-test/implied-timescales validation infrastructure in one package.

**Implementation implications:** Core `chaoslang` remains dependency-free; `deeptime_backend` is a lazy-imported optional module. CLI uses `dt-` prefix for deeptime-backed symbolizers. VAMP (non-reversible) is the default to preserve directional grammar; TICA (reversible) is opt-in via `--reversible`.
