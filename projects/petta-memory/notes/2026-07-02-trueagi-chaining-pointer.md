## Why it may matter

Ben noted this repository contains interesting, experimental, somewhat scattered code around PeTTa/PLN chaining by Nil Geisweiller. As the `petta-memory` subagent proceeds with the MesTTo pi-PLN / PeTTaChainer path, it should at some point inspect whether this related chaining work has useful ideas.

A lightweight web fetch of the GitHub page described the repository as containing experiments on backward chaining, forward chaining, iterative chaining, dependent types, lambda abstraction, modal logic, probabilistic backward chaining, a PLN prototype, PLN-based inference control, Roman Treutlein's argument-set chainer on "Light PLN", and a MeTTa backward/forward chaining module.

## How to use this pointer

- Treat the repository as exploratory external source material, not as an authoritative dependency.
- Inspect code and provenance before adopting any design.
- Candidate comparison axes:
  - PeTTaChainer `compileadd` / add-path bottlenecks;
  - PLN truth-value and evidence-count mechanics;
  - backward/forward chaining control strategy;
  - inference-control ideas for context-rich OmegaClaw experiential learning;
  - simple reusable test fixtures or minimal chainer examples.
- If useful, create a proper research-library sidecar and/or local checkout under `projects/petta-memory/repos/` with pinned commit provenance.
