\section{Question, preregistration, and verdict}
The experiment asked whether giving the same frozen-GPT-2 CAROM architecture
three times as many optimizer updates would raise in-distribution endpoint
accuracy while preserving causal trajectory evidence and improving held-out
length-5 (L5) execution. The primary target was final L2--4 accuracy above
0.55; the strong target was at least 0.65. Neither target was met. The final
accuracy was 0.1888 and the best retained checkpoint reached only 0.3268.

This was not a continuation of the successful 4,000-step checkpoint. It was a
fresh seed-0 training run whose OneCycleLR schedule was redefined over 12,000
steps. Consequently, it tests a compound change: more examples \emph{and} a
three-times-stretched learning-rate trajectory.

\section{Task and mechanism}
Each synthetic example contains six symbols in $\mathbb{Z}_8$ and a program of
two to five primitive transforms. Natural-language command spans are encoded by
the final hidden layer of frozen GPT-2-small (124M parameters, width 768). The
trainable CAROM side predicts command dependencies, compiles them into GLV
inhibition, routes command representations over reusable neural operators, and
executes a 72-step recurrent workspace trajectory. Training uses program lengths
2--4; length 5 is held out as structural extrapolation.

Endpoint slot accuracy, dependency-edge accuracy, repaired itinerary metrics,
causal trajectory replacements, and an L5 integration-budget sweep are all
reported. High itinerary $\tau$ is never read alone: an incomplete trajectory
can preserve pairwise order among the few modes it visits.

\section{Failure analysis}
\obs Three signatures coincide: endpoint loss worsens immediately after step
3,000; itinerary structure collapses; and the natural-trajectory advantage
vanishes. Edge accuracy does not collapse. This localizes the damage downstream
of, or orthogonal to, edge supervision.

\inferr The most economical explanation is that stretching OneCycleLR exposed
the model to a long high-LR interval and displaced the useful step-3,000 basin.
At step 3,000 the 12k run uses LR 0.001872, versus 0.000565 at the same step of
the 4k schedule. At step 4,000 the 12k run is near maximum LR, whereas the 4k
run has annealed to effectively zero. The timing is unusually specific.

\hypo Other live explanations are (i) a seed-0 optimization bifurcation not
reproducible across seeds; (ii) high LR interacting particularly with routing
or GLV parameters; (iii) loss-term imbalance, since edge performance stays
high while endpoint behavior fails; and (iv) a training/evaluation mismatch.
The present single run cannot apportion these effects.

\section{What the next experiment must distinguish}
This report intentionally does not declare one replacement configuration. The
independent reviewers are asked to rank designs that separate duration from LR
schedule, preferably with inexpensive gates:
\begin{enumerate}
\item resume the successful 4k checkpoint with a low constant or cosine-decay
LR, preserving the known basin;
\item repeat a fresh 12k run with lower peak LR and early stopping on the fixed
corpus;
\item use parameter-group LRs or freeze the already-solved edge head;
\item replicate the leading setting across seeds before mechanistic claims;
\item add gradient norms, per-loss terms, routing entropy, and repaired
swap/JVP probes so the next failure is identifiable while it happens.
\end{enumerate}

Any next run should checkpoint frequently through steps 2,000--5,000, monitor a
fixed validation panel, and stop when both endpoint accuracy and causal gap
degrade persistently. Selection must be declared in advance to avoid treating
the best of many checkpoints as an unbiased final result.

\section{Limitations and epistemic status}
\begin{itemize}
\item One seed gives no variance estimate.
\item Training duration and LR trajectory changed together.
\item The online and frozen evaluations use different sample streams; only the
frozen panel is used for checkpoint comparisons.
\item The forced intervention also changes dwell/amplitude, so it isolates more
than order.
\item No repaired v3 commutator, schedule-stability, or decisiveness probe was
run; no claim of learned commutation is licensed.
\item TinyLM comparison values are from the matched earlier record, not rerun
in this experiment.
\end{itemize}
