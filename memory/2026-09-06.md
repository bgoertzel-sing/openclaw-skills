# 2026-09-06 — VM2 Protocosmo OpenClaw Gateway Repair

**Summary:** Fixed @Protocosmobot on VM2 (rnd-auto-elija-first-2-60ce4d65a6) after it was returning "⚠️ Something went wrong while processing your request" errors.

**Root cause:** Multiple configuration and permission issues:
1. Broken bind mounts — `/hive/protocosmo/{config,state,secrets,activation}` were missing inside the proto-hive Docker container
2. Config file owned by root:root with mode 600 — gateway running as uid 11001 couldn't read it
3. Container missing `CAP_FOWNER` and `CAP_CHOWN` capabilities — OpenClaw's permission hardening failed
4. `/run/proto-hive/status` tmpfs mode 711 — agent_worker (uid 11001) couldn't create status files
5. OpenRouter provider not configured — only `ollama` (local) and `openai` providers available
6. Default model was `ollama/qwen2.5:7b` (7B local model, limited quality)

**Fixes applied:**
1. Fixed `/opt/proto-hive-runtime/protocosmo/config/openclaw.json` permissions: `chmod 644` and `chown 11001:10001`
2. Recreated proto-hive container with added capabilities: `--cap-add FOWNER --cap-add CHOWN`
3. Added `--tmpfs /run/proto-hive:mode=1777` to container creation
4. Added OpenRouter provider to config with `api: openai-completions`
5. Copied auth profiles from Pop!_OS to VM2 (OpenRouter key, OpenAI OAuth tokens for both accounts)
6. Changed default model from `ollama/qwen2.5:7b` to `openrouter/z-ai/glm-4.7`

**OpenAI OAuth status:** Already working via existing OAuth tokens in state database. Models: `openai/gpt-5.6-sol`, `openai/gpt-6-astra`, `openai/gpt-6-sol-preview`, `openai/gpt-6-sol`.

**Current state:**
- Gateway: reachable, active
- Default model: `openrouter/z-ai/glm-4.7` (4k ctx, warm up 30s)
- OpenAI OAuth: functional
- Telegram: channel ON / SETUP

**Architecture notes:**
- VM2 runs proto-hive inside a Docker container (container ID: `30e7614eea0a`)
- `/opt/proto-hive-runtime:/hive:rw` bind mount makes `/opt/proto-hive-runtime/protocosmo/` accessible as `/hive/protocosmo/` inside the container
- Supervisor (PID 1) starts agent_worker processes with `demote()` to uid 11001 (for protocosmo), 11003 (protomega), 11004 (protomega2)
- Gateway processes run as uid 11001 (inherit from agent_worker for protocosmo)
- OpenClaw binary: `/hive/protocosmo/state/openclaw-local-20260829T010608Z/openclaw/openclaw.mjs`
