# Daily Memory Notes

Create one file per local calendar day: `YYYY-MM-DD.md`.

Recommended sections:

```markdown
# YYYY-MM-DD

## Work performed

## Decisions and results

## Open loops

## Project/file pointers

## Memory candidates
```

Daily notes are chronological and may be rough. Promote stable facts to project records or `MEMORY.md`; do not copy entire conversations.
