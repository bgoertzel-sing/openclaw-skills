## 12:23 PDT — Protomega repair: root causes found and fixed

**Three defects fixed, end-to-end verified:**

1. **Boolean marshaling (the core silence):** `helper.is_new_message` returned Python
   `True`/`False`. Janus converts those to grounded expressions `(@ true)`/`(@ false)`,
   not MeTTa atoms. The loop's `(if $msgnew ...)` never matched, so the LLM-call branch
   never fired after dequeue — every message silently dropped. Fix: return `1`/`0` ints,
   compare with `(== $msgnew 1)` at three sites in `loop.metta`.

2. **Double-poller race:** two swipl processes (started 12:16 and 12:17 PDT, likely
   restart crossing gateway restart) both polled @Protomegabot's token. getUpdates is
   destructive-ack: whichever polls first consumes the update; the other never sees it.
   Ben's messages went into a zombie queue nobody read. Fix: killed all, started exactly
   one process (pid 2515207).

3. **Triage history poisoning:** triage prompt was being written into `history.metta`
   as if it were a user message, causing recursive meta-garbage. Fix: `OPENCLAW_TRIAGE=0`
   in run script; triage layer bypassed entirely.
