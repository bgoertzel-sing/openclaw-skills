## specatom-hs: isolated component detection - 21:30

Added isolated component detection to the information-flow validation pass in `projects/specatom-hs/repos/specatom-hs`:

- **Isolated component detection**: After reachability analysis, a broader verb regex (`ISOLATED_COMPONENT_RE`) finds components mentioned with non-edge data-flow verbs (`receives data from`, `feeds into`, `flows to/from/into`, `provides to`, `gets from`, `pulls from`, `pushes to`) that do not produce explicit `DataFlowEdge` atoms. Components mentioned with these broader verbs but not appearing in any edge are "isolated" — they indicate underspecified dependencies or missing declarations.
